Week 1: Yellowstone gRPC Geyser Streaming & Memepool Telemetry Sept 18, 2026 • Workshop 1

Key Technical Learning: Standard HTTP JSON-RPC polling inherently drops sub-second memepool trades. Building low-latency indexing requires connecting directly to Yellowstone gRPC Geyser streaming plugins with zero-copy binary deserialization to catch whale movements (> $15k) and pool graduations in real-time.

Shipped Project Artifact

Real-time Solana memepool monitor, whale tracker, and DEX liquidity indexer using Solami APIs. 7/7 tests passed.

Week 2: Meteora Dynamic Bonding Curves & DAMM v2 Migration Sept 25, 2026 • Workshop 2

Key Technical Learning: Linear bonding curves are easily exploited by sandwich arbitrage bots. Dynamic Bonding Curves (DBC) allow math-driven S-curves, Exponential, and Corridor models that protect early buyers and smoothly transition reserves into DAMM v2 liquidity pools without price shock.

Shipped Project Artifact
meteora-dbc-toolkit ↗

Mathematical preset engine, DAMM v2 migration simulator, and interactive Chart.js visualizer. 7/7 tests passed.

Blocker Overcome
64.64 Fixed-Point Precision Loss

Reconciled floating-point drift with BigInt integer basis-point scaling for exact Meteora CLI compatibility.

Week 3: Autonomous AI Agent Tooling & Prediction Market Oracles Oct 02, 2026 • Workshop 3

Key Technical Learning: Social prediction markets are plagued by retail emotional bias. Building autonomous trading agents requires fusing statistical fair probability models with Half-Kelly risk allocation to isolate positive expected value (+EV) edges.

Shipped Project Artifact

Autonomous prediction market terminal, edge evaluator, and Half-Kelly allocator for Panta API. 6/6 tests passed.

Blocker Overcome
Boundary Odds Instability

Applied Laplace smoothing to eliminate division-by-zero singularities near 0% and 100% odds.
